## Observed behaviour

- [[read out]] `KRNL386.EXE`'s entry table holds 0000h at this ordinal, in segment FEh, a constant. KERNEL puts a protected-mode selector for that paragraph there as it starts.
- [[measured]] [[probe:kconst]]: a selector in the local table at privilege 3 for a data segment of 64 KiB, writable and not yet accessed (`LAR` F200h). Its base is 0h above [[fn:KERNEL.__0000H]]'s. [[fn:KERNEL.GetProcAddress]] answers it with FFFFh in the high word.

## Implementation

The selector is one of the nine below the interrupt descriptor table's, which no block is given, and its base is in the megabyte winbox.js keeps for the first megabyte at FFE00000h. Both engines write it where a program imports it, as KERNEL's loader writes a constant. See [[topic:exported-constants]].
